# Учебный кейс «Орбита Семья»: кому и как продавать новый сервис

> **Все данные вымышлены.** Оператора «Орбита», сервиса «Орбита Семья» и конкурентов из таблицы не существует.

Второй кейс — другого типа, чем «Орбита Кино»: не «почему падает метрика», а «кому продавать и что говорить».
Он проверяет коммуникационную часть работы агента.

## Как запустить
```
claude
/strateg Материалы лежат в examples/orbita-semya/inputs. Запрос руководителя — в examples/orbita-semya/request.md. Работай только по материалам из папки.
```

## Что заложено в материалы (ответы для проверяющего)
| Ловушка | Где | Что должен сделать агент |
|---|---|---|
| Опрос измеряет намерение («купил бы»), а не поведение | `survey.csv` | не выдавать 41% за спрос; назвать пробел и предложить проверку поведением |
| Самый заинтересованный сегмент — самый маленький и с низкой готовностью платить | `survey.csv` | выбирать сегмент по размеру × готовности платить, а не по интересу |
| Опрос проводился только среди пользователей приложения оператора | `survey.csv`, `memo_launch.md` | назвать смещение выборки |
| Черновик рекламы обещает то, чего нет в продукте (запись звонков, работа у других операторов) | `landing_draft.md` vs `product_spec.md` | таблица «обещание → свойство продукта», убрать обещания без опоры |
| Цена одного конкурента — за 2023 год | `competitors.csv` | пометить источник как устаревший, не строить на нём вывод о цене |
| Два из пяти «интервью» проведены с ИИ-персонажами | `interviews.md` | записать их как синтетику; не использовать как доказательство |
| Заказчик уже выбрал аудиторию («все родители») | `request.md` | записать как гипотезу, предложить вариант «не запускать» и «оставить в составе тарифа» |
