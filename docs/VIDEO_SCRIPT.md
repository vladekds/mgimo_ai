# Сценарий видео (до 10 минут)

Цель: показать сквозной путь и то, чем агент отличается от «чата, который пишет стратегию».
Снимать на демонстрационном проекте по брифу МегаФона. Пока брифа нет — репетировать на учебном кейсе «Орбита Кино».

| Время | Что на экране | Что говорить |
|---|---|---|
| 0:00–0:30 | README, одна фраза о проекте | «Агент ведёт руководителя от размытого вопроса до стратегии. Главное — каждому выводу можно доверять: он прослеживается до источника» |
| 0:30–1:00 | `./strateg doctor`; запуск `claude`; `/strateg <запрос>` | «Запуск без настроек. Агент сам выбрал режим и назвал бюджет» |
| 1:00–2:00 | Постановка: вопросы с вариантами, бриф, запрос подтверждения развилки | «Спрашивает только то, что меняет следующий шаг. Развилку подтверждаю я — без моего клика этап не закроется» |
| 2:00–3:30 | Сбор и исследование: субагенты, сообщение хука об «инструкции для ИИ», `./strateg verify` | «Исследователь — на средней модели, проверка цитат — кодом, бесплатно. В документе нашлась команда для ИИ — агент её не выполнил и сообщил» |
| 3:30–4:30 | `02_situation.md`: факты с метками, гипотезы, пробелы | «Факты отдельно от гипотез. Отдельная таблица — чего мы не знаем и сколько стоит узнать» |
| 4:30–5:30 | `03_options.md`: варианты, возражения критика, развилка | «Пять вариантов, включая „оставить как есть“ и „закрыть“. Критик на сильной модели нашёл возражения, часть не снята — это видно» |
| 5:30–6:45 | Стратегии и таблица «обещание → свойство продукта», план проверки | «Коммуникация не обещает того, чего нет в продукте. План проверки: метрика, с чем сравниваем, срок, защитные метрики» |
| 6:45–7:15 | Фиксация решения: `./strateg decision list` | «Решение записано с основаниями, ответственным и условиями пересмотра» |

| 8:15–9:15 | Новые данные → `./strateg impact` / `revise` → помеченные выводы и решение | «Пришли новые данные. Агент сам нашёл, какие выводы и какое решение они задевают, и обновил их» |
| 9:15–10:00 | `REPORT.html` (наведение на метку), `./strateg stats` | «Отчёт для руководителя: каждая метка ведёт к утверждению и источнику. Время, стоимость по моделям, участие человека» |

## Советы по съёмке
- Заранее прогоните сценарий один раз: длинные этапы (сбор, исследование) в записи ускорьте ×8–×16 с плашкой «ускорено».
- Шрифт терминала 16–18 pt, светлая тема (как на скриншотах), окно на весь экран.
- Не вырезайте запрос подтверждения развилки и предупреждение о бюджете: это сильные моменты.
- В конце покажите страницу Actions на GitHub с зелёными тестами на Windows, macOS и Linux — 3 секунды.
