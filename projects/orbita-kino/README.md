# Проект «Орбита Кино» — эталонный прогон на учебном кейсе

> Данные вымышлены (см. `examples/orbita-kino/README.md`). Проект показывает, как выглядит работа агента «изнутри».

**Состояние:** экспресс-режим, пройдены постановка, сбор, исследование; этап «Варианты» остановлен **на развилке** —
агент ждёт выбора человека. Дополнительно сработало правило бюджета: лимит $2 исчерпан, агент остановился и спрашивает, поднимать ли лимит.

**Как продолжить (в любой среде):** `./strateg use orbita-kino`, затем в чате: «на чём остановились?».

**Что посмотреть:**
- `outputs/REPORT.html` — отчёт для руководителя (откройте в браузере);
- `outputs/03_options.md` — пять вариантов и не снятые возражения критика;
- `journal.md` — журнал: найденная в записке «инструкция для ИИ», сверка цитат, пересмотр выводов после критики;
- `work/analysis_retention.py` и `.out.txt` — воспроизводимый расчёт (`./strateg py projects/orbita-kino/work/analysis_retention.py`).

**Какие ловушки кейса агент нашёл:** эффект состава когорт; неподтверждённая версия «контент»; два определения удержания (52% и 35%);
неполные когорты; вставленная в документ инструкция для ИИ; малое число интервью; незаметные условия автопродления.

**Честные оговорки об этом прогоне:**
- оркестратором была сильная модель в длинной сессии разработки, поэтому стоимость ($2,74 до развилки) выше, чем в чистом запуске;
- критик (devils-advocate) нашёл в черновике агента ошибки: модельные оценки были записаны как факты, а гипотеза о тарифе опиралась
  на одного респондента вместо заявленных двух. Исправления видны в журнале и истории реестра (`history.jsonl`).
