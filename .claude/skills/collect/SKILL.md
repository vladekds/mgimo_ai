# Этап 2. Сбор материалов

Метод: `knowledge/methods/evidence.md` (шкала надёжности A–E, правила цитирования).

## Шаги
1. **Материалы пользователя** из `inputs/`: для каждого файла
   - PDF/DOCX/PPTX/XLSX/HTML → `./strateg ingest <файл>` (текст появится в `sources/`);
   - CSV/XLSX с данными → профилирование `./strateg profile <файл>` (листы, столбцы, периоды, пропуски);
   - изображения/скриншоты → читай напрямую (инструмент Read) или передай `ux-analyst`.
   Регистрируй: `strateg source add --kind doc|table|data|image|user --path <путь> --title … --reliability A` (собственные материалы — A, если не сказано иное).
2. **Открытые источники**: по вопросам из брифа составь 5–10 поисковых направлений (рынок, конкуренты, аудитория,
   регулирование, отзывы пользователей, бенчмарки метрик). Для объёмного поиска вызови субагента `researcher`
   со списком вопросов. Разрешённые источники: открытые сайты, отчёты, СМИ, магазины приложений, отзывы, официальная отчётность.
3. **Сохраняй снимок** важных веб-страниц: ключевые цитаты/цифры в `sources/S-xxx.md` (заголовок, URL, дата обращения, выдержки) и `--snapshot` в `source add`. Это защищает от исчезновения страницы.
4. **Извлекай факты сразу**: `strateg claim add --type fact --text "…" --source S-xxx --evidence "цитата / стр. / ячейка" --confidence …`.
   Одна мысль = одно утверждение. Цифры — с единицами, периодом и географией.
5. **Противоречия** между источниками не усредняй: заведи оба факта и `gap`/`hypothesis` о причине расхождения.
6. Сообщи пользователю: сколько источников, какие самые сильные, чего не хватает (и не может ли он это дать).
7. `strateg stage collect done`.

## Качество
- Каждый факт: источник + цитата/место + период. Надёжность честная (блог — не A).
- Отзывы и форумы — D: годятся для гипотез о болях, не для оценки распространённости.
