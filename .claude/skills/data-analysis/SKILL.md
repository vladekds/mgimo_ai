# Анализ данных

Чек-лист: `knowledge/methods/data-analysis.md`.

1. **Профиль**: `python3 scripts/tools/profile_table.py <файл>` — строки, столбцы, типы, пропуски, диапазоны дат, дубли.
2. **Проверка смысла**: что означает каждый показатель, единицы (руб/тыс. руб, %/п.п.), период, география, источник.
   Неясно — спроси пользователя или запиши `gap`. Не угадывай определения метрик молча.
3. **Расчёт только скриптом**: пиши `work/analysis_<тема>.py` (pandas, если установлен, иначе csv из стандартной библиотеки),
   который читает исходник и печатает результат. Никаких «посчитал в уме». Скрипт и вывод — часть доказательства.
   Для объёмных задач вызови субагента `data-analyst`.
4. **Регистрация**: результат расчёта = источник `--kind data --path work/analysis_<тема>.py` + факты с `--evidence "вывод скрипта: …"`.
5. **Осторожность**: малые выборки, сезонность, изменение определения метрики, эффект выжившего, корреляция ≠ причина.
   Ограничения — в текст и `gap`.
