# Итоговый отчёт

1. `./strateg verify`, затем `./strateg check` — исправь все ❌; ⚠️ либо исправь, либо явно объясни в отчёте.
2. Проверь, что в `outputs/` есть 01–06 (07 — если решение принято). Нет — сообщи, каких частей нет и почему.
3. Сверху каждого документа — **резюме для руководителя** (5 строк): вопрос → ответ → почему → главный риск → что сделать на этой неделе.
4. `strateg report` → `outputs/REPORT.md`. HTML-версия для руководителя: `./strateg html` → `outputs/REPORT.html` (кликабельные метки [F-…], реестр с фильтрами, источники, решения, стоимость). Красная метка в HTML = ссылка на несуществующее утверждение — исправь.
5. Сообщи пользователю: где отчёт, сводку `./strateg stats` (время, стоимость, участие человека), что осталось неизвестным.
