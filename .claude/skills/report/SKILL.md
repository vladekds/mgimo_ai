# Итоговый отчёт

1. `strateg check` — исправь все ❌; ⚠️ либо исправь, либо явно объясни в отчёте.
2. Проверь, что в `outputs/` есть 01–06 (07 — если решение принято). Нет — сообщи, каких частей нет и почему.
3. Сверху каждого документа — **резюме для руководителя** (5 строк): вопрос → ответ → почему → главный риск → что сделать на этой неделе.
4. `strateg report` → `outputs/REPORT.md`. HTML-версия: `python3 scripts/tools/render_html.py` (если есть) → `outputs/REPORT.html`.
5. Сообщи пользователю: где отчёт, сколько стоило (`strateg cost`), что осталось неизвестным.
