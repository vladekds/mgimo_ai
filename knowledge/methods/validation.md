# План проверки

Для каждой ключевой ставки:
| Поле | Содержание |
|---|---|
| Гипотеза | Если [действие], то [метрика] изменится на [величина] у [сегмент], потому что [механизм] |
| База сравнения | A/B-тест / контрольный регион / период до-после с поправкой на сезон / бенчмарк |
| Метрика успеха | одна главная, определение и источник данных |
| Порог решения | заранее: «успех, если ≥ X; провал, если ≤ Y; между — продлеваем» |
| Срок и объём | минимальная длительность (≥1 полный цикл использования) и объём выборки (оценка) |
| Защитные метрики | что не должно ухудшиться: отток ядра, NPS, жалобы, выручка, нагрузка на поддержку |
| Нежелательные последствия | каннибализация, раздражение, обучение ждать скидок, репутация |
| Действия по итогам | при успехе / провале / неопределённости |

Дешёвые методы до разработки: фейковая дверь (кнопка-заглушка), лендинг с предзаказом, тест сообщений, ручной консьерж-сервис, пилот на малой доле.
Размер выборки для конверсии (грубо): n на группу ≈ 16 × p(1−p) / δ², где δ — минимальный значимый эффект в абсолютных долях.
