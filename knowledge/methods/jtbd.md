# Работа, которую нанимают сделать (Jobs To Be Done)

Формула: **Когда** [ситуация], **я хочу** [мотивация], **чтобы** [ожидаемый результат].

- Описывает ситуацию и прогресс, а не демографию. Один человек может иметь разные «работы».
- Конкуренты — всё, чем человек решает ту же задачу сейчас, включая «ничего не делать», Excel, знакомого, бесплатное приложение.
- Силы выбора: толчок (боль текущего способа) + притяжение (обещание нового) против тревоги (риск нового) + привычки (инерция).
  Коммуникация и продукт должны усиливать первые две и ослаблять вторые.
- Источник формулировок — реальные интервью и отзывы (D/B), синтетика — только для черновика.
