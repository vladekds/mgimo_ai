# Постановка задачи

**Хорошо поставленная задача = решение, которое надо принять + варианты + критерий выбора + срок + получатель.**

## Пять вопросов постановки
1. **Какое решение будет принято по итогам?** (запустить / изменить / закрыть / перераспределить бюджет / выбрать сегмент)
2. **Кто принимает решение и в каком виде ему нужен результат?** (руководитель продукта, комитет, команда маркетинга)
3. **Что считается успехом?** Метрика, порог, горизонт. Если нет — предложить.
4. **Что нельзя менять?** Бюджет, сроки, бренд, технологии, регуляторика, обязательства перед партнёрами.
5. **Что уже известно и что есть из данных?** Отделить данные от мнений заказчика (мнения → гипотезы).

## Типовые размытые запросы и их переформулировка
| Запрос | Возможные решения за ним |
|---|---|
| «Почему падает удержание?» | где чинить (онбординг / ценность / цена / качество); спасать ли продукт; какие 1–2 меры в квартал |
| «Кому и как продавать новый сервис?» | выбор первого сегмента; модель монетизации; каналы запуска |
| «Что сказать аудитории, чтобы поняла ценность?» | позиционирование; ключевое сообщение; какой барьер снимать первым |
| «Стоит ли запускать X?» | запуск / пилот / отказ; критерии go/no-go |

## Ловушки
- Решение уже принято, нужен «обоснуй» — назвать это вслух; рассмотреть альтернативы честно.
- Вопрос «изучить рынок» без решения — бесконечное исследование. Спросить: «что вы сделаете иначе в зависимости от ответа?».
- Симптом вместо проблемы: падение метрики может быть артефактом измерения (смена методики, сезонность, сбой трекинга).

## Вопросы, способные изменить решение
В конце постановки перечислить 3–7 вопросов, ответ на которые меняет выбор. Они — основа плана исследования.
