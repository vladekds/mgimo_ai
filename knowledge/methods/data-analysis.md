# Чек-лист анализа данных

До расчёта: определение каждой метрики · единицы · период и часовой пояс · география · кто и как собирал · изменялась ли методика ·
пропуски · дубли · выбросы · полнота последнего периода (неполный месяц!).

Удержание: когорты по дате первого действия; удержание N-го дня/месяца = активные в периоде N / размер когорты; сравнивать когорты одного возраста.
Воронка: шаг → конверсия → время между шагами; смотреть по сегментам и каналам.
Сравнение периодов: учитывать сезонность (год к году), изменения цены, маркетинговые кампании.
Причинность: корреляция ≠ причина; для причинных выводов нужен эксперимент или квазиэксперимент.
Воспроизводимость: скрипт + вывод в `work/`; любой может перезапустить и получить тот же результат.
