# База методических знаний «Стратега»

Постоянные знания: методы, шкалы, чек-листы и шаблоны. Не меняются от проекта к проекту и не содержат фактов о конкретных компаниях.
Факты по задаче живут только в `projects/<slug>/` с источниками.

| Файл | Когда открывать |
|---|---|
| `methods/problem-framing.md` | этап frame: как превратить запрос в решаемый вопрос |
| `methods/evidence.md` | всегда: типы утверждений, шкала надёжности A–E, цитирование |
| `methods/research-planning.md` | этап research: план от решения, ценность информации, триангуляция |
| `methods/jtbd.md` | аудитория и её задача |
| `methods/options-and-objections.md` | этап options: разные варианты, возражения, pre-mortem |
| `methods/unit-economics.md` | связь пользы с затратами и доходами |
| `methods/product-strategy.md` | этап strategy: продуктовая часть |
| `methods/comms-strategy.md` | этап strategy: коммуникационная часть |
| `methods/validation.md` | план проверки и эксперименты |
| `methods/decision-tracking.md` | этап decide: решения, обязательства, пересмотр |
| `methods/interviews.md` | интервью и модельные респонденты |
| `methods/data-analysis.md` | расчёты и проверка данных |
| `methods/ux-heuristics.md` | разбор интерфейсов |
| `methods/digital-products-metrics.md` | справочник метрик цифровых и телеком-продуктов |
| `templates/*.md` | шаблоны результатов 01–07 |
